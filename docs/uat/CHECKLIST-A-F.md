# 龍角鎮 UI/UX 檢核標準（Product Builder 自訂，2026-11-10 09:46）

檢查方式總則：Playwright 跑完整新手旅程（新帳號 → 撿蛋 → 領養 → 家 → 出門 → 信物 → 接下 → 我做到了 → 收藏櫃 → 第 2 階信 → 設定），手機 390x844 與桌面 1280x800 各一次，每一個狀態截圖；自動檢查用 DOM 斷言，視覺項目由我看截圖逐條打勾。任一 P0 不過 = 不合格。

## A. 操作與按鈕（P0）
A1 每個彈窗／慶祝／全螢幕畫面都有明確主按鈕（動詞文字，如「收下星星」），可另加右上 X；不可只靠點旁邊、滑掉、計時消失才能離開。〔檢查：每個 [role=dialog]/overlay 內至少 1 個 <button> 主要樣式；搜尋文案「點旁邊」「點任意處」=0〕
A2 所有可執行動作都是 <button> 或 <a> 且有按鈕外觀；不得用純文字或 div onclick 當操作。〔檢查：可點元素皆為 button/a；無 cursor:pointer 的純 span/div〕
A3 每個畫面不捲動範圍內恰好 1 個主按鈕（primary 樣式），次要動作明顯較弱。〔檢查：計數 .primary/data-variant=primary 可見數 ==1〕
A4 點擊區 ≥44x44px。〔檢查：所有可見 button/a boundingBox〕
A5 每次點擊有回饋：按下狀態、送出中 loading/disabled，防重複點擊。〔檢查：連點主按鈕 2 次只送 1 次請求〕
A6 提示（toast）不遮住主按鈕、不擋輸入；重要結果不只用 toast 呈現。

## B. 流程連續性（P0）
B1 從家出發，第一個獎勵 ≤3 次點擊。〔檢查：腳本計數〕
B2 每個畫面都有清楚的下一步與返回路徑；關掉彈窗後回到合理狀態且畫面已更新（星星數、收藏數、按鈕狀態）。〔檢查：關閉後斷言數值變化〕
B3 新手路徑無死路：任何頁面 2 下內可回家。
B4 重新整理任何頁面後狀態不遺失、不重播已看過的動畫。
B5 同一概念全程同一名稱（寶寶／信物／收藏櫃／星星），不混用舊詞。

## C. 文案語氣（P0）
C1 新手路徑零 AI 術語：AI、MCP、token、agent、provider、事蹟、鏡子、許可證、發現匣、隨筆。〔檢查：innerText 掃描〕
C2 零說教：無「你應該」「越小越好」「映照」「可能的自己」這類勵志／反思語氣。〔檢查：關鍵字掃描＋我讀全部文案〕
C3 無錯字、重複字（如「那那」）、無內部編號（pq_ 等）。〔檢查：正則 /(.)\1/ 人工複核、/[a-z]{2}_[A-Za-z0-9]/〕
C4 語氣輕鬆、像遊戲角色說話，句子短（≤25 字為主）。

## D. 視覺一致性（P1）
D1 一套按鈕樣式（主／次／文字連結三級），圓角、高度、字級一致。
D2 間距用固定刻度（4/8 倍數），卡片與彈窗樣式統一。
D3 文字對比 ≥4.5:1（大字 ≥3:1）；無文字被截斷、重疊、溢出。〔檢查：axe-core color-contrast；截圖目視〕
D4 無版面跳動（CLS），圖片有尺寸。
D5 手機與桌面都好看：桌面不是被拉寬的手機，也不是 27 個按鈕擠一起。

## E. 養成感（P1）
E1 寶寶在家有存在感（大、會動、點了有反應）。
E2 每次完成都有看得見的成長（星星、階段進度、配件／收藏變化）。
E3 收藏櫃有已收集／未收集（灰剪影）與 n/N 進度。
E4 每日回來的理由清楚（今天能做什麼、還剩什麼）。

## F. 技術品質（P0）
F1 console error / pageerror = 0；API 4xx/5xx（非預期）= 0。
F2 鍵盤可操作、焦點可見、dialog 有 aria-modal 與標題、Esc 可關（但不是唯一方式）。
F3 動畫不阻擋輸入，支援 prefers-reduced-motion。
F4 typecheck / test / build 全過。

## 判定
P0 全過 + P1 ≥90% 才算合格。不合格項列入下一批修正，修完重跑整份檢核。
