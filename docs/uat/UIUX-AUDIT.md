## 結論

從家到看見 ★ +1，現在要點 **5** 下：出門逛逛 → 好耶 → 我也去摸摸看 → 好，接下了！ → 我做到了。主人要的是 3 下。

## 設計系統（之後每一批都照這個，不再各做各的）

### 按鈕三級

| 級 | 類名 | 用法 | 外觀 |
|---|---|---|---|
| 主 | `.btn.primary` | 這一屏只有一顆。動詞，例如「收下星星」「帶牠回家」「出門逛逛」 | 實心、圓角 999px、最小 44×44、寬最多 420px、在欄裡水平置中。不要被卡片拉滿整列 |
| 次 | `.btn.ghost` | 返回、先不要、收起來 | 透明底、線條邊、同樣高度與圓角 |
| 危險 | `.btn.danger` | 只有刪帳號這類不可逆 | 不和主按鈕搶色，不做成 primary |
| 圖示 | `.icon-btn` | 關閉、郵筒、設定 | 44×44 圓形，一定有 `aria-label` |

可執行動作只使用 `button` 或做成按鈕的 `a`。句子裡不再塞可點的純文字。`span`／`div` 不設 `cursor: pointer`。

按下：`transform: translateY(1px)`。送出：立刻鎖住（同步 ref，不等 re-render），文字改成「……中」，`aria-busy`。

### 彈窗

每一個 `role="dialog"`：

- `aria-modal="true"`，有標題（看得到或給螢幕閱讀器用的標題）
- 右上 X，44×44，`aria-label="關閉"`
- 一顆主按鈕，動詞
- 需要反悔時加一顆次按鈕
- 不點遮罩關閉。Esc 會關，但不是唯一的關法
- 用 portal 掛到 `document.body`。後面的主按鈕以 `visibility: hidden` 退出「可見」計數，並 `inert`，鍵盤進不了後面
- 焦點進到主按鈕，Tab 在彈窗內循環，關掉後焦點回到原處
- 重要結果（星星、信物）寫在彈窗裡，不靠 toast

關掉的意思要和文案一致：

- 慶祝的「收下星星」才寫入完成。X／Esc／「先不要」回到列表，步驟還在，星星不變
- 信的 X／Esc／「先收起來」只關視窗，信留在郵筒。「先不要這個朋友」才永久收起，而且字要這樣寫

### Toast

- 放在頂欄下方，不蓋住主按鈕、不擋輸入
- 有「好」可以關，也會自己淡出
- 只用於複本、已儲存這種附帶消息。星星、信、背包不靠它當唯一結果

### 色彩與字

紙色 `#fbf6ec`、卡片 `#fffdf8`、墨色 `#4a3f35` 維持。

| 用途 | 色 | 對比 |
|---|---|---|
| 內文 | `#4a3f35` on `#fbf6ec` | 9.5:1 |
| 輔助字 | `#5e5146` on `#fbf6ec` | ≥ 7:1 |
| 主按鈕 | 墨色字 `#1c2416` on `#6f9a5c` | ≥ 4.5:1（不再用白字壓在淺綠色上） |
| 深色模式主按鈕 | `#14210f` on `#8fbd7b` | ≥ 4.5:1 |
| 危險 | 維持，確認 ≥ 4.5:1 | |

字：系統裡的 Noto Sans TC／蘋方。標題 1.35–1.6rem，內文 16px／1.7。彈窗短句以 25 字內為主。

### 間距

只使用 4 的倍數：4、8、12、16、24、32。卡片與彈窗同一套圓角與 2px 邊。彈窗最大寬 360。頁面內容最大寬維持 1080，但主按鈕自己不跟它變寬。

### 動作

- 短位移用現有的 hop／pop，不擋其他按鈕
- 孵化、出門這種「請等我」的畫面，必須有一顆可以立刻按的按鈕
- `prefers-reduced-motion: reduce` 時不播、也不要改用計時器把人帶走

### 名字

全程只用：寶寶、信物、收藏櫃、星星、郵筒。新手看得見的字不用：紀念品、明信片、事蹟、鏡子、發現匣、第一步、隨筆、AI、MCP。導覽第三格維持「圖鑑」（它是位置），頁面標題用「收藏櫃」。

## 分批修法

每一批做完，新手從蛋走到信都還是一條完整的路，不會半套舊彈窗、半套新按鈕。對應的舊測試在同一批裡改掉。

### 第 1 批 — 三下拿到第一顆星

從家到 ★ 對話：出門逛逛 → 我也去摸摸看 → 我做到了。

- 背包不再擋路。第一次出門，背包直接出現在寶寶身上，信物卡同時出來，附一句「小背包背好了。」
- 「我也去摸摸看」直接建立步驟並進「我接下的事」，不再經過表單
- 慶祝：主按鈕「收下星星」、右上 X、次按鈕「先不要」。不點外面。表情先選，再收下
- 今天這顆還沒接下的信物，重新整理後仍在家裡的卡片上；收藏櫃明細也能「我也去摸摸看」
- 散步進行中的句子改成「小龍還在外面晃……」，不要說晚點回來
- 送出用同步鎖，連點只打一次

驗收：B1 點擊數 ≤ 3。A1 慶祝有主按鈕且沒有「點旁邊」。B2 收下後星星變 1，先不要則星星仍是 0、步驟還在。B4 重新整理家，信物卡還在、不重播散步。

### 第 2 批 — 每一站都有下一顆和回去的路

- 孵化改成按鈕「去找牠」，取消計時跳頁。重新整理仍停在孵化，直到按下去
- 領養：第 2、3 步有「上一步」；最後一顆叫「帶牠回家」。步驟與名字寫進 sessionStorage
- 收藏櫃頁有一顆主按鈕「回小龍身邊」。明細是正式彈窗，「好」或「我也去摸摸看」
- 未滿第 2 階的郵筒是彈窗「還沒有信。」＋「好」，不把人送進「通知」
- 信：X／先收起來不刪信；另有一句誠實的「先不要這個朋友」
- 地圖、空地點、空的我接下的事，各有一顆主按鈕可以繼續或回家
- 彈窗打開時，背後的主按鈕不算可見

驗收：旅程上每一屏可見主按鈕恰好 1。任一頁兩下內可以到家（關彈窗一下，再點家）。A1 的每一個 dialog 都有按鈕。孵化不會自己消失。

### 第 3 批 — 同一套說法

- 收藏櫃副標改掉「那一排」和「紀念品櫃」，改成「收藏櫃裡，「地名」還空著一個位子。」
- 連接頁預設只說會說話的朋友，主按鈕「回小龍身邊」。MCP、網址、AI 收到預設關上的「進階」裡
- 地圖的無障礙名稱改說信物，不說事蹟
- 同意頁「成為你的角色」只留一處。按鈕改成和站內同一級，對比合格
- 家裡今天已經出門、又沒有待接下的信物時，主按鈕改成「去收藏櫃看看」，並寫還缺多少

驗收：C1、C2 在必經頁的 `innerText` 為 0。C3 沒有「那那」、沒有內部編號。B5 新手看得見的標題用收藏櫃／信物／星星／寶寶。

### 第 4 批 — 點得到、看得清、鍵盤走得完

- 上面的色彩表落地。主按鈕改深色字
- 所有可見 `button`／`a` 至少 44×44：品牌、頂欄、色票、地圖店家、條款、設定列、複製鈕、縮放
- toast 移到上方並加「好」
- axe `color-contrast` 在必經頁為 0
- 桌面主按鈕最寬 420，置中
- 地圖載入用固定高度，避免先空再跳

驗收：A4、A6、D3。F2：dialog 有 `aria-modal` 與標題，Esc 能關，同時看得到主按鈕。F3：關動畫時孵化仍等按鈕，不自己跳。

### 第 5 批 — 檢核腳本與修完截圖

- `e2e/uiux-checklist.spec.ts` 跑完整旅程，手機與桌面各一次
- 自動項：A1–A5、B1–B3、C1–C3、F1–F2、D3（axe）
