# 龍角鎮：小龍有自己的今天

版本：2026-11-10，基底 PR #5 e6bc733。產品方向來自 Willy 11:03 指示。

交付位置說明：執行環境只允許寫本專案及 /tmp。本檔對應 /workspace/llm-world-uat/design/GDD-living-world.md；CHECKLIST-G.md、verify-codex 與 lane-d-status.md 同樣先收在本專案 docs，未宣稱已寫入指定的外部路徑。

## 核心體驗

打開家，小龍已經有一段今天的生活：「去河邊學跳石頭，鞋子濕了。」玩家可以看看牠的日記、陪牠完成一個心願，或者只摸摸頭。交換真實經驗仍是世界的心臟，但不再是唯一玩法。生活活動都是虛構的小龍生活；有真人來源的內容一定另標「鎮民的心意」，保留來源與同意界線。

不做餓死、病倒、連續登入、落後倒數、付費抽獎。休息也是正常選擇。星星只沿用現有真人完成流程；虛構活動取得生活收藏，不能冒充真人經驗、刷成長星或送到公開牆。

## 每日循環與自主生活

台北日界 00:00，伺服器決定日期、時段與季節。每天給一個穩定的自主生活片段、一個心願與一個可選的幫忙；日記首頁以今天優先，保存近期 60 天。離線不跑排程、不逐日補帳、不扣數值；回來只產生當天一段。GET 讀取不寫 DB，當天自主片段以日子和角色 id 決定，陪玩提交時寫入快照。

玩家從家以次要按鈕「小龍的今天」進入。原出門→接下→完成三下閉環保留。生活頁只有「陪牠去玩」一顆主按鈕。選活動後看事件預覽，再按「就去這裡」；完成用對話框「收好紀念品」，可 X 或 Esc，關閉後看到更新的日記、心情與收藏。每項活動每天一次、最多七種，提交有防重複與伺服器鎖；不需付錢或等待。每日推薦不同，但全部常駐，不製造錯過焦慮。

## 相遇與驚喜

鎮民是明確的虛構角色。玩家小龍只從 sharing.life.allowVisits=true 且非本人中選，畫面只顯示名字與外觀，不帶 email、位置、私人日記或現實上線資訊。預設不串門；生活頁設定以明確按鈕「讓小龍去串門／先不串門」切換，撤回後未來讀取不再出現。相簿保存自家小龍與鎮民的敘事；玩家相遇只在當下顯示，不永久複製對方資料。沒有符合的朋友就讓小栗出現，絕不假造真人玩家。

同一天同活動的插曲由 server seed 決定，預覽與結果一致；季節活動每季可重玩、未拿到也不鎖後續。資料定義包含 emoji、標題、地點、story、wish、help、reward、category；增加活動不需再做一套任務程式。

## 真實經驗如何流入世界

沿用已公開且通過 moderation 的 deeds，私密／撤回／刪除內容不可用。生活頁的「鎮民的心意」區顯示一則即時查到的公開內容，明確標示是他人分享；按「去看看這份心意」走既有地點→信物卡→接下流程。只用公開 title 與角色稱呼，不引用私人 note、summary 原文、精確地址或其他聯絡資訊。來源每次讀取重新查可見性，不把他人的文句快取進私人日記。

由使用者自己的 LLM 帶回經驗時，沿用現有 MCP discovery、first_step_propose、本人確認與公開審核。AI 完成後仍私密；本人預覽後決定公開，匿名讀取前後 404/200 與 token 撤銷測試保留。生活系統不把活動產生物寫入 deeds，也不自動代人同意分享。

## 第 2 階後的會說話朋友

既有連接入口仍到第 2 階才開放。新增唯讀 life_get：讓朋友讀今天的小龍心情、心願、活動與自己的日記；不給其他人的私人資訊、不替玩家按完成或開串門。朋友可講今天的小故事、用 world_discover 找到相關真實經驗、帶回 discovery、提議本人可確認的小步驟、代詢商家。給工具的 instructions 明確區分虛構活動與真實經驗，不把遊戲活動報成真人做過。

## 收藏與房間

現有信物九格照舊，信物代表鎮民心意。新生活收藏另放在「生活收藏」頁，四類：旅行紀念品、朋友相簿、衣服、房間佈置；固定七格與 n/7，未取得灰色顯示。每格可開有名稱、來源與獲得日的對話框；只有已取得衣服、佈置可以「穿上／擺在家裡」。家裡顯示所選物件，可從收藏頁收回；沒有貨幣、購買確認或商城。活動獎勵皆唯一，以 activity id 去重。

## 資料與 API

沿用 characters.sharing.life，server 寫入且 characterInput.sharing 不接受外部 life 覆寫。型別含 version:1、days[{day,autonomous,entries[{activityId,at}]}]、inventory[{activityId,earnedOn}]、outfit、decoration、allowVisits。日記 60 天、背包上限活動總數，不無限增長。保留現有 sharing 其他 key。

GET /api/me/life：即時今天、活動可用性、日記、心情、公開來源入口與同意的相遇。POST /api/me/life/activities {activityId}：transaction SELECT FOR UPDATE 同一角色，去重後更新 sharing.life、lastActiveAt；不碰星星。PATCH /api/me/life {allowVisits?,outfit?,decoration?}：同鎖、驗證已擁有、null 表收回。GET 讀不寫；跨日與跨頁都以 server 資料為準。沿用既有 requireUser、moderation、錯誤處理及帳號刪除 cascade。

不新增 DB 或 migration；只測 longjiao_laned_test/e2e，服務埠 4131–4139。若長期超過 JSON 寫入成本，後續抽 life_days/event_history 表，這版不先鋪無用表。

## 畫面與互動規格

| 畫面／狀態 | 內容與主要操作 | 返回與邊界 |
| --- | --- | --- |
| 家 | 原寶寶／三下領星；今日摘要次要入口與穿戴／擺設 | 導覽回家；不新增第二顆 primary |
| 今天載入／錯誤 | 載入提示；失敗一顆「再看一次」 | 回小龍身邊；不洩漏後端錯誤 |
| 今天 | 今日片段、心情、心願／幫忙、時段季節、日記、活動與朋友 | 「陪牠去玩」主操作；收藏／來源／串門均次要 |
| 選活動 | 七種選擇用有按鈕外觀的 radio，選後預覽 | 「就去這裡」主操作；取消回今天；完成項 disabled |
| 活動結果 | 角色故事與獎勵名稱 | 「收好紀念品」、X、Esc；焦點回觸發點 |
| 生活收藏 | n/7 與四類；灰格提示來處；已收集可開明細 | 「回小龍身邊」主操作；今天次要 |
| 收藏明細 | 所得物件、日期、故事 | 衣服／擺設以「穿上／擺在家裡」主操作；其餘「收好」；X、Esc |
| 第 2 階信／連接／設定 | 沿用現有頁與入口；朋友可讀生活 | 不把技術術語放到新手路徑 |

對話框用既有 Dialog（焦點圈、aria-modal、名稱、Esc）；背景不可點擊關閉，按鈕 ≥44px。每屏一個 primary，送出 disabled/aria-busy + useRef 阻擋重入；server 防重。動畫遵守 reduced-motion，不用動畫延遲提交。
