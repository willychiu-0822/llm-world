# 架構總覽（一頁版）

> 詳細內容見 [CORE-LOOP.md](./CORE-LOOP.md)

## 目的
讓人因為**好玩**而來，在過程中自然地去做想做、但不敢或沒動力做的事。**改變是副產品，不是入口。**

## 行動的四個條件
**想知道 × 相信做得到 × 第一步可及 × 有人在乎**：每個機制都必須服務其中之一。

## 參與者
| 參與者 | 定位 |
|---|---|
| 用戶 | 真人 + 自訂的 AI 角色（可與本人完全不同） |
| 提供者 | 現實中提供「試一次」機會的人或單位 |
| AI（系統） | 策展與媒合，不捏造事蹟 |

## 主閉環
```
① 設定想做的事 → ② AI 角色發現 → ③ 查看發現 → ④ 也想做 → ⑤ 定義第一步
       ▲                                                        │
⑨ 繼續設定 ← ⑧ 新事蹟、累積成就 ← ⑦ 紀錄 ← ⑥ 執行第一步（AI 或本人）
```
- **第一步**：小、具體、由用戶定義；只問「讓 AI 做，還是本人做」，兩者地位相同。
- **紀錄**：自動為主；做前／做後隨筆，不強迫，預設只有自己看得到。

## 世界的內容
| 類型 | 規則 |
|---|---|
| 表達（外觀、個性、想要的能力） | 可以虛構 |
| 背景（AI 角色自主活動） | 不算事蹟 |
| 事蹟（執行者：AI 角色 / 本人） | 必須有真人意志，標示執行者 |
| 試用機會（提供者） | 真實的第一步 |

優先呈現**相似的人的第一次**，不呈現高手的精彩片段。

## 角色的作用
**方向**（決定看到什麼）· **探索者**（替你發現）· **許可證**（「是我的角色想試」）· **容器**（累積你的事蹟）

## 流通的價值（不是點數）
**火種**（想知道）· **證明**（相信做得到）· **路徑**（第一步可及）· **見證**（有人在乎）

## 供需
| 參與者 | 給 | 拿 |
|---|---|---|
| 用戶 | 見證、新事蹟 | 發現、路徑、試用機會 |
| 經驗者 | 第一步經驗、回答（可由 AI 代答）、同行 | 被跟隨、被需要 |
| 提供者 | 好的第一步、過程資訊 | 有興趣的新人、真實需求訊號 |

**互相推動的四個機制**
1. **取用即供給**：你的新事蹟就是下一個人的發現
2. **跟隨即回謝**：被跟著做，是給予者最強的回饋
3. **前一步原則**：媒合只多走一步的人，每個程度都有供給
4. **提供者的供給就是世界的內容**：提供者不能買曝光，只能把第一次辦好

**角色流動**：新手 → 經驗者 → 同行、帶領 → 推廣者 → 在新領域又是新手

## 飛輪
```
真人產生事蹟 → 相似的人發現 → 也想做 → 定義並執行第一步 → 新事蹟
      ▲                                                  │
      └──────────────── 被跟隨（回謝）◀───────────────────┘
世界越豐富 = 真人的行動越多 = 有改變的人越多
```

## 生活紀錄
只做兩件事：**找時機**（日曆、位置）、**降低紀錄成本**（出席確認、健康 App、照片、隨筆）。成就是鏡子：足跡、角色與自己的重疊、做前做後隨筆並排。原始資料只留在用戶端。

## 守則
1. 入口是樂趣　2. 每一步都可停可退　3. 靠拉力不靠推力　4. 事蹟必須有真人意志　5. 呈現可達成的事　6. 取用即供給、跟隨即回謝　7. 不用點數，成就是鏡子　8. 世界不是廣告　9. 角色是可能，不是應該　10. 試一次不綁約　11. AI 不捏造事蹟，逐步讓位

## 健康指標
③→④ 想做率 · ④→⑤ 定義率 · ⑥ 完成率 · 執行者分布 · 新事蹟被發現時間 · 被跟隨率 · ⑨ 回流率 · 隨筆分享率 · 真人供給占比
