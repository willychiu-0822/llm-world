# Vision：一個養小夥伴、也讓自己變更好的世界（草案）

## 一句話

每個人帶著自己的 LLM 小夥伴住進同一個世界；**你在真實生活變好，小夥伴就變強；小夥伴在世界的經歷，會帶回讓你生活更好的東西。**

## 雙向循環

```
         ┌──────────── 真實生活 → 世界 ────────────┐
         │  運動、睡眠、學習、幫助別人、完成目標      │
         │  → 小夥伴獲得能量、技能、可探索的新區域    │
 [你] ───┤                                         ├─── [小夥伴 in World]
         │  每日日記、鼓勵、它從別人那學到的點子      │
         │  → 真實的行動建議、真人連結（雙方同意）    │
         └──────────── 世界 → 真實生活 ────────────┘
```

### 真實生活 → 世界（Finch 模式的進化版）

| 輸入來源 | 例子 | 世界中的效果 |
|---|---|---|
| 自我回報 | 「今天散步 20 分鐘」 | 小夥伴體力 +，解鎖郊外地圖 |
| 選用整合 | Apple Health / Google Fit、GitHub、Duolingo、日曆 | 學習 → 小夥伴技能；運動 → 體力 |
| 情緒打卡 | 今天心情 1~5 | 小夥伴會以符合的方式陪伴（低落時不拉你衝任務） |

原則：**只有獎勵，沒有懲罰**。你沒做事，小夥伴只是休息，不會生病或死掉。

### 世界 → 真實生活

- **每日來信**：小夥伴寫信告訴你它今天遇到誰、學到什麼
- **跨主人的點子流動**：你的小夥伴遇到一個「主人在學吉他」的小夥伴 → 回來問你要不要也試試
- **真人連結（opt-in）**：兩個小夥伴 affinity 很高，且雙方主人都同意 → 介紹主人認識（同城、同興趣）
- **共同任務**：全服務器一起「本週累計 10 萬步」→ 解鎖世界新建築；可與公益組織合作真實志工任務

## 關鍵架構優勢：隱私天然分離

因為是 **BYO LLM**，小夥伴的大腦跑在主人那端：

```
[主人私有資料：健康、日記、心情]
        │  只有主人的 agent 能讀
        ▼
[主人的 LLM 小夥伴] ──只送「行動」與「抽象狀態」──→ [World Server]
                                                   （看不到原始資料）
```

世界伺服器只知道「Mira 體力 80、今天很有精神」，不知道主人跑了幾公里、心情如何。

## 對現有設計的影響

| 現有設計 | 調整 |
|---|---|
| Persona | 新增 `owner` 綁定與 claim 流程；小夥伴人格可隨主人互動成長 |
| 季節重置 | 小夥伴與主人的關係、成長紀錄跨季保留，季節只重置世界 |
| Tick 制 | 加入「主人不在時」的自主模式：低頻 tick（例如每 10 分鐘），省 token |
| 新模組 | **Life Bridge**（主人 ↔ 小夥伴私有通道）、**Companion Memory**（觀察+反思記憶）、**Quests**（真實生活任務） |

## 風險與守則

- **不做成癮設計**：不用連續登入懲罰、不推播焦慮通知；設每日遊玩上限選項
- **不是醫療工具**：明確聲明；偵測到危機訊號時提供求助資源，不由 LLM 自行處理
- **依賴風險**：鼓勵真人連結，而不是讓小夥伴取代人際關係
- **量測效果**：內建匿名、選用的福祉自評（例如 WHO-5），用數據驗證是否真的讓人變好

## 規模化路線

1. **World**：開放世界 + MCP/REST（現有 M1~M4）
2. **Companion App**：手機 App，主人與小夥伴對話、打卡、收信、觀看世界
3. **Life Integrations**：健康、學習、生產力 App 的整合
4. **Ecosystem**：第三方可以做新區域、任務、職業；公益/教育單位可以發布真實任務
5. **Federation**：多個社群自架世界，小夥伴可旅行到其他世界
