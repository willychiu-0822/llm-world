# Vision

> 機制細節見 [OVERVIEW.md](./OVERVIEW.md)、[CORE-LOOP.md](./CORE-LOOP.md)

## 一句話

**一個充滿真人真實事蹟的世界：你帶著自己的 AI 角色進來玩，看見跟你相似的人做到了什麼，然後也定義並踏出自己的第一步。**

## 我們相信的事

1. **人來，是為了好玩。** 改變是投入後的副產品，不是入口。
2. **能讓人相信「我也可以」的，只有真人。** 虛擬角色做到的事沒有說服力，所以世界裡的事蹟都必須來自真人的意志。
3. **最好的榜樣只比你多走一步。** 相似的人的第一次，比高手的精彩片段更能讓人行動。
4. **第一步可以很小，也可以交給 AI。** 打聽、研究、先在世界試做，都是完整的第一步。
5. **給予本身就是回報。** 被別人跟著做，比任何點數都更讓人願意繼續分享。

## 世界是什麼

| 是 | 不是 |
|---|---|
| 大家真實事蹟的集合 | AI 自己編出來的故事 |
| 依興趣與相似度策展的發現 | 付費曝光的廣告 |
| 每一步都可以停、可以退 | 連續登入、焦慮推播、懲罰 |
| 成就是鏡子（足跡、重疊、隨筆） | 點數、等級、排行榜 |

## 誰在這個世界裡

| 參與者 | 他們在這裡得到什麼 |
|---|---|
| **用戶** | 好玩的發現、一個低門檻的第一步、被看見 |
| **經驗者** | 被跟隨、被需要；分享可以交給自己的 AI 角色代答 |
| **提供者** | 真正有興趣、已經暖身過的新人，以及真實的需求訊號 |

同一個人會在不同領域扮演不同角色：新手 → 經驗者 → 陪同、帶領 → 推廣者 → 在新領域又是新手。

## 關鍵架構優勢：隱私天然分離

因為是 **BYO LLM**，角色的大腦跑在用戶端：

```
[用戶私有資料：日曆、位置、健康紀錄、隨筆]
        │  只有用戶自己的 agent 能讀
        ▼
[用戶的 AI 角色] ──只送「事蹟」與「抽象結果」──→ [World Server]
                                                （看不到原始資料）
```

隨筆預設只有自己看得到；用戶選擇分享時，才會成為事蹟的一部分。

## 風險與守則

- **不做成癮設計**：沒有連續登入獎勵與懲罰，不推播焦慮通知
- **世界不是廣告**：推薦依興趣與相似度，不依提供者是否付費
- **試一次不綁約**：提供者不得在試用後強迫推銷
- **不是醫療工具**：明確聲明；偵測到危機訊號時提供求助資源，不由 LLM 自行處理
- **依賴風險**：AI 是潤滑劑，目標是讓真人之間的連結取代 AI 供給
- **量測效果**：以第一步完成率、被跟隨率、隨筆分享率等指標驗證是否真的讓人往前走

## 規模化路線

1. **World**：開放世界 + MCP/REST，用戶的 AI 角色可以接入
2. **Companion App**：手機上設定想做的事、查看發現、定義第一步、寫隨筆
3. **Providers**：活動推廣者、教室、社團加入，提供試用機會與自己的 agent
4. **Life Integrations**：日曆、位置、健康 App 等選用整合，用於找時機與自動紀錄
5. **Federation**：社群自架世界，事蹟與角色可以在世界之間流通
