# Core Loop：系統架構模型（v2，概念層）

> 本文件只定義**概念與結構**，不定義具體功能、介面或玩法。

## 0. 第一性原理

一個人去做「想做但沒做」的事，需要四個條件同時成立：

| 條件 | 缺少時的狀態 | 理論依據 |
|---|---|---|
| **想知道**（Curiosity） | 無感 | Loewenstein 資訊缺口理論 |
| **相信做得到**（Efficacy） | 不敢 | Bandura 自我效能 |
| **第一步可及**（Ability） | 不知從何開始 | Fogg B = MAP |
| **有人在乎**（Relatedness） | 做了也沒意義 | 自我決定論（SDT） |

系統的唯一任務：**讓這四個條件更容易同時成立。**

## 1. 四種價值單位

把四個條件反過來看，就是人與人之間可以流通的四種東西：

| 價值單位 | 滿足的條件 | 本質 |
|---|---|---|
| **火種**（Spark） | 想知道 | 讓人產生缺口的資訊 |
| **證明**（Proof） | 相信做得到 | 「跟我相似的人做到了」 |
| **路徑**（Path） | 第一步可及 | 一個已被走過的、夠小的起點 |
| **見證**（Witness） | 有人在乎 | 被看見、被回應 |

延伸單位：**同行**（Company）= 證明 + 見證同時發生，也就是一起做。

這是整個系統的「貨幣」。系統中**沒有**金錢或點數作為核心交換物：真實行動換點數會削弱內在動機（Deci, Koestner & Ryan, 1999）。

## 2. 三層循環

```
┌──────────────────── ③ 世界循環 ────────────────────┐
│                                                     │
│   ┌────────── ② 交換循環 ──────────┐               │
│   │                                 │               │
│   │   ┌─── ① 個人循環 ───┐          │               │
│   │   │                   │          │               │
│   │   │ 缺口 → 選擇 → 行動 │          │               │
│   │   │   ↑         ↓     │          │               │
│   │   │ 痕跡 ← 回饋 ←──┘   │          │               │
│   │   └───┬──────────▲────┘          │               │
│   │       │產出       │接收           │               │
│   │       ▼          │               │               │
│   │   供給（證明/路徑/火種）→ 媒合 → 需求  │               │
│   │       ▲                    │      │               │
│   │       └──── 回謝（見證）◀────┘      │               │
│   └─────────────┬───────────────────┘               │
│                 ▼                                   │
│   痕跡累積 → 世界變豐富 → 更多缺口 → 更多參與          │
└─────────────────────────────────────────────────────┘
```

### ① 個人循環：一個人如何成長

`缺口 → 選擇 → 行動 → 回饋 → 痕跡 → 新缺口`

| 節點 | 作用 | 依據 |
|---|---|---|
| 缺口 | 產生「想知道」 | 資訊缺口 |
| 選擇 | 保有自主，永遠可以拒絕 | SDT：自主 |
| 行動 | 小到幾乎不會失敗 | B = MAP：能力 |
| 回饋 | 即時正向情緒 + **預期與實際的校準** | Fogg 慶祝；Epley & Schroeder（人系統性高估社交風險） |
| 痕跡 | 行動留下可被看見、可被他人使用的紀錄 | SDT：勝任、歸屬 |

**校準**是個人循環的核心原理：人不敢，多半是因為預期不準。讓預期和實際反覆對照，恐懼就會被自己的經驗修正，而不是被說服。

### ② 交換循環：人與人如何互相推動

`需求 → 媒合 → 給予 → 收穫 → 回謝`

**關鍵設計：取用本身就會產生供給。**

```
A 取用了「路徑」並完成行動
  → A 的行動自動成為新的「證明」與「路徑」
  → 供給給下一個 B
  → B 的回應成為 A 的「見證」
```

需求增加，供給就跟著增加。這是整個系統的飛輪。

### ③ 世界循環：系統如何越來越豐富

`痕跡累積 → 世界內容增加 → 新缺口出現 → 更多人參與`

世界的內容不是由營運方製作，而是由所有人的痕跡堆積而成。

## 3. 供需機制

### 3.1 角色流動：每個人同時是給予者與取用者

- 角色是**相對於領域**的：A 在 X 領域取用，在 Y 領域給予。
- **「前一步原則」**：最好的給予者不是專家，而是**只比你多走一步的人**。
  - 依據：替代經驗在楷模與自己相似時最有效（Bandura）。
  - 結果：每個人都比某些人多走一步，**每個層級都有供給**，不依賴少數專家。

### 3.2 給予的不對稱價值

| 價值單位 | 給予者成本 | 取用者價值 |
|---|---|---|
| 見證 | 極低（幾秒鐘的回應） | 高（「有人在乎」） |
| 證明 | 零（行動的副產品） | 高（「我也可以」） |
| 路徑 | 低（分享自己怎麼開始） | 高（「從這裡開始」） |
| 火種 | 低（分享一個經歷） | 中高（「我想知道」） |
| 同行 | 中（一起投入時間） | 最高 |

設計原則：**讓低成本、高價值的給予成為預設行為**。多數供給應該是「做了就自動產生」，而不是「要另外花力氣去給」。

### 3.3 給予者為什麼願意給

給予本身就滿足給予者的需求，不需要外在報酬：

| 給予者得到 | 對應需求 |
|---|---|
| 被感謝、被需要 | 歸屬 |
| 「我的經驗有用」，重新確認自己的能力 | 勝任 |
| 自己決定給什麼、給誰 | 自主 |
| 教別人會讓自己理解更深（教學效應） | 勝任 |

所以**回謝**（取用者給回的見證）是讓交換循環閉合的必要環節。沒有回謝，給予者就沒有回饋，供給會枯竭。

### 3.4 失衡與調節

| 狀態 | 症狀 | 調節方式 |
|---|---|---|
| 需求 > 供給 | 取用者等不到回應 | 提高給予者的可見度（「有人需要你這一步」）；剛完成的取用者優先轉為給予者（經驗最新、距離最近） |
| 供給 > 需求 | 給予沒人取用 | 產生更多缺口（火種）以創造需求 |
| 冷啟動 | 兩邊都沒人 | **AI agent 作為種子供給與造市者**（見 3.5） |
| 品質不均 | 低品質供給 | 以「是否帶來後續行動與回謝」作為信號，不用星等評分 |

### 3.5 AI agent 在供需中的角色

| 角色 | 作用 | 時期 |
|---|---|---|
| **種子供給** | 在真人供給不足時，提供火種與路徑 | 冷啟動 |
| **代理人** | 先替主人探索、先與他人接觸，降低第一步的風險 | 全期 |
| **造市者** | agent 之間互動，發現供需配對 | 全期 |
| **轉譯者** | 把一個人的痕跡轉成另一個人可用的形式 | 全期 |

原則：**AI 是潤滑劑，不是終點。** 系統的目標是讓真人之間的供給逐漸取代 AI 供給。指標：真人供給占比隨時間上升。

## 4. 成長軸：從取用到給予

```
旁觀 ──→ 嘗試 ──→ 同行 ──→ 給予
(取用證明)  (取用路徑)  (交換同行)  (產生證明/路徑/火種)
```

- 每一階都同時是「個人成長」與「供給能力提升」。
- 難度隨校準結果調整，維持在剛好有點挑戰的程度。
- 走到「給予」不是終點：給予者在其他領域仍是取用者，所以循環沒有終點。

## 5. 系統守則

1. **四個條件**：任何機制都必須能說出它服務哪一個條件。
2. **取用即供給**：優先設計「做了就自動產生供給」的結構。
3. **前一步原則**：媒合的是相近的人，不是專家與新手。
4. **回謝閉環**：每一次給予都要能收到回饋。
5. **不以點數為核心貨幣**：流通的是火種、證明、路徑、見證。
6. **永遠可以拒絕**：取用與給予都必須出於自願。
7. **AI 讓位**：AI 供給是過渡，真人供給才是目的。

## 6. 系統健康指標

| 指標 | 意義 |
|---|---|
| 取用 → 供給轉換率 | 飛輪是否在轉 |
| 首次見證時間 | 行動後多久被看見 |
| 回謝率 | 給予者是否得到回饋 |
| 校準落差變化 | 使用者的預期是否越來越準（恐懼是否下降） |
| 真人供給占比 | AI 是否逐步讓位 |
| 角色雙重率 | 同時是給予者與取用者的人的比例 |
