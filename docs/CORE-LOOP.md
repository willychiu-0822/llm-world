# Core Loop：系統架構模型（v4，概念層）

> 本文件只定義**概念與結構**，不定義具體功能、介面或玩法。

## 0. 第一性原理

### 0.1 人來，是為了好玩，不是為了改變

「改變自己」本身就有門檻：要承認不足、要付出努力、可能失敗。如果入口是「變更好」，只有已經有動力的人會進來，而那些人最不需要我們。

所以：

- **入口是樂趣**，改變不是目的。
- **改變是副產品**：投入越深，越自然地延伸到真實生活。
- 每一層投入**本身都要完整地好玩**，不能是「為了下一層而忍受的過程」。

依據：Lazzaro 的樂趣四鑰（Four Keys to Fun），可以排成一條「成本由低到高」的軸：

| 樂趣類型 | 來源 | 投入成本 |
|---|---|---|
| Easy Fun（輕鬆樂趣） | 新奇、好奇、探索 | 最低 |
| People Fun（人際樂趣） | 與他人互動 | 中 |
| Hard Fun（挑戰樂趣） | 克服困難的成就感 | 中高 |
| Serious Fun（意義樂趣） | 成長、改變、做出影響 | 最高 |

「讓人變更好」屬於 Serious Fun，**應該在最後出現，而不是在入口。** Lazzaro 的研究也發現，暢銷遊戲多半至少具備其中三種。

### 0.2 一個人去做「想做但沒做」的事，需要四個條件

| 條件 | 理論依據 |
|---|---|
| **想知道**（Curiosity） | Loewenstein 資訊缺口理論 |
| **相信做得到**（Efficacy） | Bandura 自我效能 |
| **第一步可及**（Ability） | Fogg B = MAP |
| **有人在乎**（Relatedness） | 自我決定論（SDT） |

這四個條件不需要使用者主動去追求。系統要讓它們**在玩的過程中自然累積**。

## 1. 個人軸：投入梯度

```
  投入成本  低 ────────────────────────────────────→ 高

  L0 看   →  L1 碰   →  L2 養   →  L3 連   →  L4 延伸
  (旁觀)    (回應)     (塑造)     (相遇)     (帶進生活)
   │         │          │          │           │
  Easy      Easy       Easy +     People     Serious
  Fun       Fun        Hard Fun   Fun        Fun
```

| 層 | 使用者在做什麼（概念） | 成本 | 樂趣來源 | 自然累積的條件 |
|---|---|---|---|---|
| **L0 看** | 觀看一個會自己發生事情的世界 | 零 | 驚喜、新奇 | 想知道 |
| **L1 碰** | 對看到的東西做出最小的回應 | 一個動作 | 看到自己的回應造成影響 | 有人在乎（雙向） |
| **L2 養** | 塑造屬於自己的那一份 | 小 | 擁有感、自我表達 | 第一步可及 |
| **L3 連** | 自己的那一份與別人的相遇 | 中 | 人際、共同經歷 | 相信做得到（看到相似的人） |
| **L4 延伸** | 把世界裡的經驗帶進真實生活 | 高 | 意義、成長 | 四個條件都具備 |

### 梯度的四個原則

1. **每一層都是終點**：停在 L0 也是完整的體驗，沒有「還沒玩完」的壓力。
2. **向外移動靠拉力，不靠推力**：往下一層走的原因必須是「好奇」或「在乎」，不能是「被要求」或「怕錯過」。
3. **可以往回走**：任何時候都能退回低成本的層。
4. **L4 不被標示為目標**：系統不告訴使用者「你應該要延伸到生活」，它只是在前面幾層玩深了之後，自然出現。

### 為什麼 L0 是「看」

- **零成本**：不需要任何決定，也不會失敗。
- **驚喜就是缺口**：v2 要使用者「踏入缺口」，但驚喜是**被動收到的缺口**，不需要任何勇氣。
- **旁觀是合法的參與**：Lave & Wenger 的「合法周邊參與」指出，新成員是從邊緣觀察開始，逐步成為核心成員。網路社群研究也發現，潛水可以是為之後參與做準備（是否如此視情境而定）。
- **旁觀別人就是替代經驗**：看到相似的人做到某件事，本身就在累積「相信做得到」。

### 為什麼 L2 是「養」

- **IKEA 效應**（Norton, Mochon & Ariely, 2012）：人會更珍惜自己參與做出來的東西，**但只限於成功完成的時候**。
  → 塑造的動作必須小到一定會成功。
- 擁有感讓使用者從「觀眾」變成「關係人」，這是之後在乎、回來的根基。

## 2. 個人內部的微循環

每一層裡都有同一個最小循環：

```
  發生 → 注意 → 回應 → 改變 → 發生
  (世界)  (人)    (人)    (世界)
```

- **發生**：世界自己會動，不靠使用者驅動（使用者不在時也一樣）。
- **注意**：使用者看到，產生驚喜或好奇。
- **回應**：使用者做出這一層成本的回應（可以不回應）。
- **改變**：回應在世界留下**可見的痕跡**，形成新的「發生」。

這個循環在 L0 只有「發生 → 注意」；越往外層，回應越深、痕跡越大。

**校準**（預期 vs 實際的對照）放在 L3–L4 才出現：只有開始碰觸真實的人際與生活時，「高估風險」才會成為阻礙（Epley & Schroeder, 2014）。

## 3. 四種價值單位

人與人之間流通的不是點數，而是能滿足四個條件的東西：

| 價值單位 | 滿足的條件 | 本質 |
|---|---|---|
| **火種**（Spark） | 想知道 | 讓人產生驚喜或好奇的事 |
| **證明**（Proof） | 相信做得到 | 「跟我相似的人做到了」 |
| **路徑**（Path） | 第一步可及 | 一個已被走過的、夠小的起點 |
| **見證**（Witness） | 有人在乎 | 被看見、被回應 |

延伸單位：**同行**（Company）= 證明 + 見證同時發生。

不以點數為核心貨幣：真實行動換點數會削弱內在動機（Deci, Koestner & Ryan, 1999）。

## 5. 供需機制

### 5.1 每一層都在交換

即使是最低成本的層，也同時在取用與給予：

| 層 | 取用 | 給予（副產品） |
|---|---|---|
| L0 看 | 火種、證明（看別人的痕跡） | 注意力（被看本身是一種微弱的見證） |
| L1 碰 | 火種 | **見證**：成本最低、價值很高的給予 |
| L2 養 | 路徑 | 火種：自己塑造的東西成為別人可看的內容 |
| L3 連 | 證明、同行 | 同行、證明 |
| L4 延伸 | 路徑、見證 | 證明、路徑：真實經驗成為別人的起點 |

**結論：只要有人在看，就有人在給。** 入口層本身就是供給的來源，不需要等使用者「成長」到某個程度才開始貢獻。

### 5.2 取用即供給

```
A 在任一層的行動 → 自動留下痕跡
  → 痕跡成為 B 在 L0 可看的「發生」（火種、證明）
  → B 在 L1 的回應成為 A 的「見證」
  → A 被看見 → 更在乎 → 往外一層
```

需求增加，供給就跟著增加。這是整個系統的飛輪。

### 5.3 前一步原則與角色流動

- 最好的給予者是**只比你多走一步的人**，不是專家。依據：楷模越相似，替代經驗的效果越強（Bandura）。
- 角色相對於領域：在 X 領域取用的人，可能在 Y 領域給予。
- 每個人都比某些人多走一步，所以**每個層級都有供給**。

### 5.4 給予的不對稱價值

| 價值單位 | 給予者成本 | 取用者價值 |
|---|---|---|
| 見證 | 極低 | 高 |
| 證明 | 零（行動的副產品） | 高 |
| 火種 | 零到低 | 中高 |
| 路徑 | 低 | 高 |
| 同行 | 中 | 最高 |

原則：**多數供給應該是「做了就自動產生」，而不是「要另外花力氣去給」。**

### 5.5 給予者為什麼願意給

| 給予者得到 | 對應需求 |
|---|---|
| 被感謝、被需要 | 歸屬 |
| 「我的經驗有用」 | 勝任 |
| 自己決定給什麼、給誰 | 自主 |

**回謝**是交換循環閉合的必要環節。沒有回謝，給予者就沒有回饋，供給就會枯竭。

### 5.6 失衡與調節

| 狀態 | 調節方式 |
|---|---|
| 需求 > 供給 | 提高給予者的可見度；剛往外走一層的人優先轉為給予者 |
| 供給 > 需求 | 讓痕跡更容易被 L0 看見，用火種創造需求 |
| 冷啟動 | AI agent 作為種子供給與造市者 |
| 品質不均 | 以「是否引發後續回應與回謝」為信號，不用評分 |

### 5.7 AI agent 的角色

| 角色 | 作用 |
|---|---|
| **世界的引擎** | 讓 L0 永遠有東西在「發生」：使用者不在時，世界也不會停 |
| **種子供給** | 真人供給不足時，提供火種與路徑 |
| **代理人** | 先替主人探索、先與他人接觸，降低 L3 的門檻 |
| **造市者 / 轉譯者** | 發現配對；把一個人的痕跡轉成另一個人可用的形式 |

原則：**AI 是潤滑劑，不是終點。** 真人供給占比應隨時間上升。

### 5.8 第一步提供者

現實中提供「試一次」機會的人或單位（教室、教練、社團、場館等）。

| 角色 | 給出 | 得到 |
|---|---|---|
| 使用者 | 出席、經驗、證明 | 低風險的第一步 |
| 提供者 | 試用機會、過程資訊、自己的 agent | 有興趣且已暖身的新人 |
| 前一步使用者 | 同行、證明 | 被需要 |
| AI agent | 媒合、轉譯 | — |

```
提供者的試用機會與 agent → 成為世界中的地點、情境、角色
  → 使用者在世界中接觸、心動、預演
  → 現實中試一次 → 留下證明 → 更多人敢去 → 需求增加
  → 更多提供者加入 → 世界更豐富 → ...
```

**提供者的供給本身就是世界的內容**：營運方不需要自己製作內容。

## 6. 角色與轉移：從世界到生活

### 6.1 角色：可以完全不同的「可能的自己」

使用者自訂角色的外觀、個性、能力，可以與真實的自己完全不同。

| 依據 | 內容 | 設計含義 |
|---|---|---|
| 可能自我（Markus & Nurius, 1986） | 「想成為的自己」會驅動行為，但前提是看起來做得到、而且連著具體計畫 | 角色必須連著第一步，否則只是幻想 |
| 普羅透斯效應（Yee & Bailenson, 2007） | 角色特質會改變人的行為，而且會延續到線下 | 角色不只是外觀，而是行為的暗示 |
| 固定角色治療（Kelly） | 讓人扮演一個新角色約兩週，以此探索新的行為方式 | 「完全不同的角色」有臨床先例 |

**角色是一張許可證**：「是我的角色想試，不是我」，可以降低被評價的恐懼。所以角色和自己差距越大，越需要角色當作掩護。

### 6.2 轉移階梯

```
旁觀 → 預演 → 承諾 → 觸發 → 扮演 → 帶回 → 融合
(世界)  (世界)  (橋)    (生活)  (生活)  (橋)    (自我)
```

| 階段 | 概念 | 依據 |
|---|---|---|
| **旁觀** | 看自己的角色在世界中做 | 替代經驗（Bandura） |
| **預演** | 在世界中走過**過程**：怎麼去、誰在那裡、前十分鐘會發生什麼 | 過程模擬比結果想像更能提升意圖與行動（Pham & Taylor；Armitage & Reidy） |
| **承諾** | 把一次嘗試變成「何時、何地、做什麼」的計畫 | 若-則計畫，94 項測試平均 d = .65（Gollwitzer & Sheeran, 2006） |
| **觸發** | 在對的時間與地點，被溫和地提醒 | B = MAP：提示（Prompt） |
| **扮演** | 以角色的身分去做這一次 | 固定角色治療；角色作為許可證 |
| **帶回** | 真實經驗以最低成本回到世界 | 痕跡、見證 |
| **融合** | 角色與自己的「重疊」被看見並增加 | 人從自己做過的事推論自己是誰（自我知覺） |

**每一階都可以停下或退回**。沒去不會受罰，只會重新安排或換一個第一步。

### 6.3 提供者在轉移中的作用

- **提供過程資訊**：讓「預演」的內容是真實的，降低不確定感。
- **提供者的 agent 住在世界裡**：使用者的角色可以先在世界中認識提供者，現實中第一次見面時，對方就不是陌生人。
- **確認出席**：讓「帶回」不需要使用者額外操作。

### 6.4 生活紀錄的角色

紀錄只做兩件事：**找到對的時機**、**降低帶回的成本**。紀錄不拿來計分或排名。

| 方向 | 紀錄來源（皆為選用） | 服務的階段 |
|---|---|---|
| 生活 → 平台 | 日曆（空檔、計畫） | 承諾、觸發 |
| | 位置（靠近相關地點、到場） | 觸發、帶回 |
| | 健康 / 運動 App | 帶回 |
| | 照片或一句話 | 帶回 |
| | 提供者的出席確認 | 帶回 |
| 平台 → 生活 | **重疊圖**：角色的特質中，哪些你已經在生活中做過 | 融合 |
| | **校準紀錄**：預期與實際的對照 | 扮演（降低下一次的恐懼） |
| | **足跡**：真實去過的地方與遇過的人 | 融合 |

**隱私原則**：原始紀錄只留在使用者端，由使用者自己的 agent 讀取；世界伺服器只收到「有去」、「去過哪類地方」等抽象結果。

## 7. 系統守則

1. **入口是樂趣**：任何入口層的機制都不能以「改變」作為訴求。
2. **每層都是終點**：停留在任何一層都是完整的體驗。
3. **拉力不是推力**：往外走只能因為好奇或在乎。
4. **四個條件**：任何機制都必須說得出它服務哪一個條件，或哪一種樂趣。
5. **取用即供給**：優先設計「做了就自動產生供給」的結構。
6. **前一步原則**：媒合相近的人。
7. **回謝閉環**：每次給予都要能收到回饋。
8. **不以點數為核心貨幣**。
9. **永遠可以拒絕、可以退回**。
10. **AI 讓位**。
11. **世界不是廣告**：推薦依使用者的興趣決定，不依提供者是否付費。
12. **角色是可能，不是應該**：不把角色與自己的差距呈現成「不足」。
13. **試一次不綁約**：提供者不得在試用後強迫推銷。
14. **紀錄是鏡子，不是計分板**。

## 8. 系統健康指標

| 指標 | 意義 |
|---|---|
| L0 停留與回訪 | 入口是否真的好玩 |
| 層間自然流動率 | 拉力是否有效（無提示下往外走的比例） |
| 取用 → 供給轉換率 | 飛輪是否在轉 |
| 首次見證時間 | 行動後多久被看見 |
| 回謝率 | 給予者是否得到回饋 |
| L4 自發比例 | 改變是否作為副產品出現 |
| 真人供給占比 | AI 是否逐步讓位 |
| 預演 → 承諾 → 出席轉換率 | 轉移階梯在哪一階卡住 |
| 二次參與率 | 試一次之後，是否自發地再去 |
| 重疊增加速度 | 角色是否真的被帶進生活 |
