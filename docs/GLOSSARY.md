# 用詞表

玩家看得到的字，同一個東西只用下面的稱呼。數字是改之前，`apps/web/src` 正式程式（不含測試、不含註解）裡出現的次數。

## 小龍

玩家養的那一隻。名字、家、今天的生活，都是牠。

改之前：小龍 67、角色 12（不含「AI 角色」這四個字）、寶寶 3。用最多的是小龍。

| 不要再用 | 改成 |
| --- | --- |
| 寶寶 | 小龍 |
| 寶寶名字 | 小龍名字 |
| 角色、角色名字、角色名、我的角色 | 小龍、小龍名字、我的小龍 |

## 會說話的朋友

玩家自己的聊天工具，連上龍角鎮、代小龍去打聽的那一位。

改之前，這個意思被分開叫過：會說話的朋友 8、AI 角色 12、你的 AI 8（其中多數是「你的 AI 角色」「你的 AI 用戶端」）、AI 用戶端 2（有一處被斷行）、幫手 1。

AI 角色次數較多，但那是「AI」加「角色」疊在一起。AI 本來就不能出現在新手看得到的畫面上，角色又比小龍少。能留在畫面上的稱呼裡，會說話的朋友最多，而且連接頁的標題、小龍的信、隱私權說明已經用它。所以全站改成會說話的朋友。

| 不要再用 | 改成 |
| --- | --- |
| 幫手 | 會說話的朋友 |
| 你的 AI、AI 用戶端、AI 角色 | 會說話的朋友 |
| AI 執行、AI 建議、AI 帶回、交給 AI | 會說話的朋友（或「交給會說話的朋友」） |
| 朋友做的、朋友的建議、朋友帶回、請朋友去逛逛、朋友幫忙 | 會說話的朋友（這些短說法指的是同一位，不是鎮上的人） |

## 留著、不要改的字

- **小幫手**：信物的名字，不是會說話的朋友。「幫手」兩個字只在「小幫手」裡可以出現。
- **OpenAI、Claude、ChatGPT、Codex**：聊天工具的產品名，寫在連接頁的進階說明裡。
- **帶朋友、朋友家、鎮上的朋友、請朋友吃**：鎮上的人或玩家自己的朋友，不是會說話的朋友。
