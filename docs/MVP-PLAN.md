# MVP v1 規劃

> 狀態：**已確認**，依本文件開發；技術細節見 [ARCHITECTURE.md](./ARCHITECTURE.md)、[PROTOCOL.md](./PROTOCOL.md)。

## 1. 目標

用最小的產品，驗證主閉環能不能轉起來：

```
① 設定想做的事 → ② AI 角色發現 → ③ 查看發現 → ④ 也想做 → ⑤ 定義第一步
       ▲                                                        │
⑨ 繼續設定 ← ⑧ 新事蹟、累積成就 ← ⑦ 紀錄 ← ⑥ 執行第一步（AI 或本人）
```

**驗收情境**：[CORE-LOOP.md](./CORE-LOOP.md) 的三個範例（小安、Leo、Mia）可以在系統中從頭到尾走完，並有自動化 E2E 測試覆蓋。

## 2. 已確認的決策

| 項目 | 決策 |
|---|---|
| AI 來源 | **只接用戶自己的 LLM**。平台不呼叫任何 LLM，所有 AI 行為都由用戶的 AI 用戶端透過 **遠端 MCP + OAuth** 執行（Claude、ChatGPT、Grok、Cursor 等） |
| 產品名稱 | **龍角鎮**（repo 名稱維持 `llm-world`） |
| 世界呈現 | **虛構的龍角鎮插畫地圖**（SVG，可縮放拖曳）+ 地點卡片；不使用真實世界地圖 |
| 地點 | **8 個固定主題區** + 萬事屋；提供者在區內**開店**；沒有提供者的事蹟落在該區的公共地點 |
| 地圖上的角色 | 顯示最近有活動的角色，出現在其最近活動的地點旁 |
| 視覺風格 | 溫暖的扁平插畫：柔和配色、圓潤造型、清晰、帶手繪繪本感（氛圍參考經典英式自然繪本；全部原創，不使用任何既有作品的角色或畫作） |
| 公開身分 | 角色名 + 「真人」標記，不顯示本名 |
| 事蹟可見度 | 預設公開，完成時可改為私人；隨筆預設只有自己看得到 |
| 初始內容 | 正式環境放**明確標示「示範」**的內容，管理者可一鍵清除 |
| 雲端 | **GCP Cloud Run + Cloud SQL（PostgreSQL）**，區域 **asia-east1（台灣）**，Cloud Run 最低執行個數 **0** |
| 網址 | 使用 Cloud Run 提供的 `*.run.app` 網址 |
| 部署方式 | **手動 gcloud 腳本** 與 **GitHub Actions 自動部署**（Workload Identity Federation）兩者都提供 |
| 登入 | 只做 Google 登入 |
| 提供者上線 | 需管理者核准 |
| AI 建議的第一步 | 狀態為草稿，需用戶在 Web 確認才成立 |
| 提供者 | **提供者自行註冊後台** |
| 技術棧 | TypeScript / Node.js 22 |

### 「只接自己的 LLM」帶來的設計結果

| 架構中的 AI 職責 | v1 的做法 |
|---|---|
| 角色的發現（②） | 用戶在自己的 AI 用戶端請角色去逛 → AI 呼叫 MCP 工具取得候選內容 → AI 自己挑選、寫一段話 → 存進用戶的「發現匣」 |
| 策展 | 伺服器做**規則式檢索**（相關、相似、第一次、一步之遙）；最後的挑選與轉譯由用戶的 AI 完成 |
| AI 執行的第一步（⑥） | 用戶的 AI 讀取待執行的 AI 步驟、執行（例如向提供者打聽、整理資訊），再回報結果，產生事蹟 |
| 提供者 agent | v1 為**結構化的提供者檔案**（過程資訊、常見問答）。用戶的 AI 提問時先查問答；沒有答案就轉成問題給提供者，在後台非同步回答 |
| 經驗者的 AI 代答 | v1 以經驗者**選擇分享的事蹟與隨筆**作為回答來源，由提問者的 AI 讀取並轉述 |
| 背景活動 | v1 不做（平台沒有自己的 LLM） |

## 3. 範圍

### 3.1 用戶端（Web，手機優先）

| 功能 | 對應步驟 |
|---|---|
| Google 登入 | — |
| 角色設定：外觀（預設角色圖 + 配色）、個性、想做的事、分享設定 | ① |
| 連接 AI：顯示 MCP 網址與 Claude / ChatGPT / Grok / Cursor 的接入說明 | — |
| 發現匣：角色帶回的發現（附角色的一段話與來源） | ②③ |
| 龍角鎮地圖：主題區、店家與公共地點、最近活動的角色；點擊開啟地點卡片（事蹟、試用機會） | ③ |
| 事蹟頁：內容、執行者標示、前人的第一步；「我也想做」按鈕 | ③④ |
| 定義第一步：參考前人的第一步、選擇執行者（AI / 本人）、何時何地、做前隨筆（選填）；本人步驟可報名試用場次並下載行事曆檔（.ics） | ⑤ |
| 我的步驟：待執行、已完成；本人步驟標記完成 + 做後隨筆（選填） | ⑥⑦ |
| 成就鏡子：足跡（去過的地點）、角色與自己的重疊（想做的事 ↔ 已完成的事蹟）、做前做後隨筆並排 | ⑧ |
| 通知：被跟隨、提供者回答了問題、AI 步驟完成 | ⑧ |

### 3.2 提供者後台（Web）

| 功能 |
|---|
| 申請成為提供者（同一個 Google 帳號），由管理者核准 |
| 在主題區開店（選擇主題區、店名、外觀），並填寫真實地址或「線上」供參加者前往 |
| 建立試用機會：一次、時長、具體時間地點、可退出、可配對同行 |
| 填寫過程資訊與常見問答；設定 AI 第一步與本人第一步的建議文字 |
| 建立場次、查看報名名單 |
| 確認出席（自動產生參加者的紀錄） |
| 需求訊號：被詢問次數、報名數、常見問題（匿名） |
| 回答用戶 AI 轉來的問題 |
| 回謝：活動被參考與跟隨的次數；參加者選擇分享的隨筆列表 |

### 3.3 MCP 伺服器（給用戶的 AI）

遠端 MCP（Streamable HTTP）+ OAuth 2.1（動態用戶端註冊、PKCE）。工具清單見 [PROTOCOL.md](./PROTOCOL.md)。

### 3.4 管理者

| 功能 |
|---|
| 核准提供者 |
| 管理示範內容（一鍵清除） |
| 基本健康指標（主閉環各步驟的數量與轉換） |
| 查看內容過濾紀錄、下架違規內容 |

### 3.5 共通機制

| 機制 | v1 做法 |
|---|---|
| 事蹟 | 執行者標示、參考來源（`related`，用於回謝）、可見度 |
| 隨筆 | 選填，預設只有自己看得到，可選擇分享到事蹟 |
| 回謝 | 定義第一步時參考了誰的事蹟 → 該事蹟主人收到「被跟隨」通知；只有本人看得到數字 |
| 內容過濾 | 關鍵字過濾管線（`off` / `log` / `filter` / `block`），只檢查公開內容 |
| 隱私 | 平台不接日曆、位置、健康資料；行事曆以 .ics 檔交給用戶自己加 |

## 4. 不在 v1 範圍

2D 小鎮、平台代管 LLM、背景活動、季節制、位置 / 健康 App 整合、事蹟驗證分級、同行配對、原生 App、推播通知、Email 通知、金流、聯邦化、多語系（v1 只有繁體中文）。

## 5. 開發階段（goal 模式依序完成）

| 階段 | 內容 | 完成條件 |
|---|---|---|
| P0 | Monorepo、Docker、DB schema 與 migration、設定與日誌 | `pnpm test` 通過、`docker compose up` 可啟動 |
| P1 | Google 登入、角色設定、地點與事蹟的資料與 API | API 整合測試通過 |
| P2 | 視覺風格、龍角鎮插畫地圖與角色圖、用戶端 Web：發現匣、地圖、事蹟、定義第一步、我的步驟、隨筆 | 元件與 API 測試通過 |
| P3 | 提供者後台與管理者核准 | 提供者流程整合測試通過 |
| P4 | MCP 伺服器 + OAuth 2.1 授權伺服器 | 以 MCP SDK 用戶端完成 OAuth 並呼叫所有工具的測試通過 |
| P5 | 策展檢索、回謝、通知、成就鏡子 | 整合測試通過 |
| P6 | 內容過濾管線 | 單元測試通過 |
| P7 | 示範內容、種子資料與 E2E 測試（小安、Leo、Mia 三個情境，Playwright + MCP 用戶端） | E2E 全數通過 |
| P8 | 部署腳本、`DEPLOYMENT.md`、`CLOUD-SETUP.md` | 文件可依步驟完成部署 |

所有開發在功能分支進行，完成後開 PR，由你 merge 與部署。

## 7. 開發期間的預設做法（不另行詢問）

| 項目 | 做法 |
|---|---|
| 分支與 PR | 在 `feat/v1-mvp` 分支開發，完成後開 PR，由你 merge |
| 第一位管理者 | 以環境變數 `ADMIN_EMAILS` 指定，部署時設定 |
| 語言與時區 | 介面只有繁體中文；時區 Asia/Taipei |
| 測試登入 | 測試與本機環境提供免 Google 的測試登入（`AUTH_DEV_LOGIN=true`），正式環境強制關閉 |
| 美術素材 | 地圖、建築、角色圖全部以程式產生的原創 SVG 製作 |
| 角色圖 | 由預設體型、配件與配色組合；用戶在角色設定中挑選 |
| 地圖上的角色 | 顯示最近 7 天有事蹟或探索紀錄的角色，每個地點最多顯示數個，其餘以「+N」表示 |
| 線上活動 | 試用機會可設為「線上」，不需實體地址 |
| 無提供者的事蹟 | 落在對應主題區的公共地點（例如音樂坊的廣場） |
| 示範內容 | 標記 `is_demo`，介面顯示「示範」；排序在真人內容之後；不觸發回謝通知；管理者可一鍵清除 |
| 內容過濾 | 預設 `filter` 模式，附基本關鍵字清單，可由設定檔擴充 |
| 速率限制 | 每個 AI 用戶端每分鐘 60 次工具呼叫 |
| 帳號刪除 | 用戶可刪除帳號與所有資料 |
| 隱私權政策與服務條款 | 提供頁面草稿，**上線前需由你審閱**；Google OAuth 同意畫面需要這兩個網址 |
| Google OAuth 審核 | 文件說明「測試模式」（最多 100 位測試用戶）與正式發布審核流程 |
| CI | PR 時自動執行型別檢查、lint、單元與整合測試 |
| MCP 工具說明 | 工具描述以英文撰寫（各家模型相容性最好），回傳內容為繁體中文 |
| Cloud SQL 規格 | 最小規格起步，文件附升級方式與預估費用 |
