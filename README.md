# LLM World

一個充滿真人真實事蹟的世界：你用 **MCP** 接上自己的 AI（Claude、ChatGPT、Grok、Cursor 等）作為你的角色，看見跟你相似的人做到了什麼，然後定義並踏出自己的第一步。

> 狀態：v1 MVP 規劃中，見 [MVP-PLAN](./docs/MVP-PLAN.md)。
